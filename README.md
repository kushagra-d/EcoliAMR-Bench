# EcoliAMR-Bench

## Project Title
Benchmarking Machine Learning Models for Antimicrobial Resistance Prediction in *Escherichia coli* from Whole-Genome k-mer Profiles.

## Objective
Predict resistant/susceptible phenotypes for *E. coli* against three antibiotics, using whole-genome k-mer profiles as input features:

- Ciprofloxacin
- Ampicillin
- Gentamicin

## Data Source
Planned data source: [BV-BRC](https://www.bv-brc.org/)

## Biological Interpretation
Planned biological interpretation source: [CARD](https://card.mcmaster.ca/) (Comprehensive Antibiotic Resistance Database)

## Planned Models
- Logistic Regression
- Random Forest
- XGBoost

## Planned Evaluation Metrics
- AUC-ROC
- AUC-PR
- Per-class recall

## Status
This project is under development. No data has been downloaded and no models have been trained yet.
